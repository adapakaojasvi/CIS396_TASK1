PROJECT TITLE
Redesign of a Website Landing Page - CODTECH Internship Landing Page

Internship Domain: Web Development
Task No: Task-1

1. OBJECTIVE
The objective of this task was to take an existing website landing page and redesign it to improve its usability, aesthetics, and conversion rate.

The old landing page was text-heavy, had no clear visual hierarchy, no clear Call-To-Action (CTA), and was not mobile-friendly. The goal of the redesign was to make the page clean, modern, user-friendly, and easy to understand in less than 5 seconds.

2. WEBSITE SELECTED FOR REDESIGN
Website: CODTECH - Internship Landing Page
Reason for Selection: CODTECH is an internship platform for students. Its landing page is the first page a student sees. If this page is confusing, students will leave without applying. So improving this page directly improves applications.

3. PROBLEM ANALYSIS - BEFORE REDESIGN
After analysing the old page, the following problems were found:

- Too much text in one place, no clear headline
- No clear CTA - user did not know where to click to apply
- All text was of same size, no visual hierarchy
- No trust signals like ratings, testimonials, stats
- Buttons were small and not mobile-friendly
- No proper spacing, sections were mixed together
- No FAQ section to clear student doubts

4. SOLUTION - AFTER REDESIGN
A new modern landing page was designed using HTML, CSS, and JavaScript in a single `index.html` file.

New Structure:
  1. Sticky Navbar: CODTECH logo + Internships, Why Us, Redesign, FAQ + Always visible Apply Now button
  2. Hero Section: Badge "Applications Open • 2026 Batch", Headline "Learn by Building. Get Hired Faster.", 2 Buttons + Stats (50,000+ Interns, 4.8 Rating, 100% Online)
  3. Dashboard Mockup: Visual card showing Internship Dashboard with course list and 78% progress bar
  4. Before → After Section: Clear comparison of what was changed
  5. Why Choose Codtech: 3 Cards - Task-Based Learning, Certificate, Mentor Support
  6. Pick Your Track: 4 Interactive Tracks - Web Dev, Python, AI/ML, Java
  7. Testimonials + FAQ: 2 student reviews + 3 FAQs to build trust
  8. Final CTA: Orange section "Ready to Start Your Internship?" + Apply Now button
  9. Footer: Copyright and Task details

5. DESIGN DECISIONS
Decision	Reason
Orange #FF4D00 + Navy #0F172A	Taken from CODTECH brand colours, creates brand identity
Inter Font	Clean, modern, highly readable on mobile and desktop
One Clear Headline + One Main CTA	User understands purpose in 5 seconds, increases applications
Card Layout + White Space	Easy to scan, reduces cognitive load
Sticky Navbar	Apply button always visible, improves conversion
Large Buttons (44px)	Easy to tap on mobile, improves usability
Stats + Testimonials + FAQ	Builds trust, removes doubts of new students
Mobile-First Responsive Design	More than 70% students visit from mobile, page works on all screens
6. TOOLS & TECHNOLOGIES USED
   - HTML5 - For page structure
   - CSS3 - For styling, Grid, Flexbox, Responsive Media Queries
   - JavaScript - For Track Selection and Apply Now popup
   - Google Fonts (Inter) - For typography
   - VS Code - For code editing
   - Browser - For testing

7. KEY FEATURES IMPLEMENTED
   - Fully responsive design for Mobile, Tablet, Desktop
   - Sticky navigation with smooth scrolling
   - Interactive track selection - click to change track details
   - Apply Now popup using JavaScript
   - Hover effects on cards and buttons
   - FAQ accordion using `<details>` tag
   - Before / After comparison for evaluation

8. HOW TO RUN THE PROJECT 
   Save the code as `index.html`
   Double-click the file OR right-click > Open with Browser
   No internet / server needed, except Google Fonts
